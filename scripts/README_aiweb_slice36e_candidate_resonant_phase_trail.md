# Slice 36E — Candidate Resonant Phase-Trail Construction

## What this slice adds

This package converts accepted Slice 36D operator-binding candidates into immutable, traceable candidate structural trails.

Each application creates a new state and preserves the prior state. The package retains source ancestry, binding ancestry, source spans, identity fields, phase candidates, branch conflicts, suspension, containment, drift indicators, completion state, and lawful non-progress reasons.

## What this slice does not add

It does not activate a core RSOC operator, select a phase, select a trail, compile meaning, infer permission, bind a capability, create a route, use a tool, access memory, perform an action, or deliver output.

## Public runtime surface

The package exports:

- immutable policy, limit, state, application, trail, set, and result records;
- explicit construction and completion enums;
- deterministic policy and limit builders;
- initial-state and successor-state constructors;
- candidate phase-trail construction;
- independent validators for every record layer.

## Default construction behavior

The default policy branches every authorized structural effect and every explicit advisory phase affinity. It creates single-binding trails and only those compound trails supported by reciprocal Slice 36D parent-child links. Competing candidates remain separate. Arbitrary neighboring candidates are not composed.

## Governing example

For `Do not install it.` the accepted predecessor chain produces eight candidate trails. These preserve prohibition, negation, reference, boundary, and loop-seal possibilities plus the explicit prohibition-to-negation parent-child compositions. The action-like source signal for `install` remains outside phase-trail operator application because no authorized grammar operator is attached to it.
