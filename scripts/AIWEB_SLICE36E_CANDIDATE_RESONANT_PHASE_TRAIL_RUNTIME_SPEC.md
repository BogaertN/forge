# AI.Web Slice 36E — Candidate Resonant Phase-Trail Construction Runtime Specification

## 1. Purpose

Slice 36E constructs deterministic candidate phase-bearing structural trails from the exact source-field projection accepted by Slice 36B and the source-bound operator candidates accepted by Slice 36D.

It is the first bounded layer in which a registered symbolic grammar-operator candidate may produce an immutable successor candidate state. It does not select a trail, select a phase, construct meaning, grant permission, bind a capability, create a route, call a tool, access memory, perform an action, or deliver output.

## 2. Required predecessor chain

The runtime accepts only the exact typed chain:

1. Slice 36A input-event custody;
2. Slice 36B deterministic source-field projection;
3. Slice 36C symbolic grammar-operator registry;
4. Slice 36D resonant operator candidate binding.

A malformed, unsupported, held, or inconsistent predecessor result cannot be silently repaired.

## 3. Transformation law

Every candidate application obeys:

```text
candidate_operator(current_candidate_state) -> successor_candidate_state
```

The predecessor state remains immutable and present in the trail. Every successor preserves:

- predecessor-state identity;
- predecessor-application identity;
- source-event identity;
- source-field projection identity;
- candidate-binding ancestry;
- identity-field identity;
- exact source-span identities;
- recursive depth;
- unresolved, conflicting, suspended, and contained branch evidence.

Correction, containment, suspension, rejection, transformation, constraint, and sealing effects create traceable successor records. No earlier state is overwritten or deleted.

## 4. Candidate-only phase law

Slice 36C phase affinities are advisory registry metadata. Slice 36E may preserve an explicitly authorized phase affinity as a candidate phase value, but it may not declare that phase selected or execute a phase transition law that has not been installed.

A change from an unassigned phase to an advisory candidate phase is therefore recorded as a contained candidate transition with the non-progress reason `phase_transition_law_not_installed`.

Slice 36E does not force all language through Φ1–Φ9, does not synthesize missing phases, and does not infer a phase from source familiarity.

## 5. Trail construction law

The default policy requires:

- one visible trail for every lawful single-binding structural effect;
- one visible branch for every explicit advisory phase affinity;
- explicit parent-to-child composition only when the Slice 36D records contain reciprocal parent and child identities;
- separate trails for materially competing candidates;
- no arbitrary neighboring-candidate composition;
- no co-application of competing candidates;
- no hidden ranking or automatic winner.

Where Slice 36C has not installed compatibility or commutation law, Slice 36E must not invent it.

## 6. RSOC boundary

The ten Slice 36B0 RSOC contracts remain disabled. Slice 36E records candidate grammar-state transformations only. It does not invoke a core RSOC operator, claim a numeric SFE transformation, change entropy numerically, or install a grammar-to-RSOC crosswalk.

`core_rsoc_operator_key` remains absent and `core_rsoc_operator_applied` remains false in every application.

## 7. Result statuses

The runtime may return:

- `ZERO_PHASE_TRAILS`;
- `ONE_PHASE_TRAIL`;
- `MULTIPLE_PHASE_TRAILS`;
- `CONFLICTING_PHASE_TRAILS`;
- `INCOMPLETE_PHASE_TRAIL`;
- `MALFORMED_PHASE_TRAIL`;
- `UNSUPPORTED_OPERATOR_SEQUENCE`;
- `DRIFT_CONTAINED`;
- `RECURSION_SUSPENDED`;
- `PHASE_TRAIL_LIMIT_EXCEEDED`;
- `PHASE_TRAIL_CONSTRUCTION_FAILED`.

Unsupported or held source remains in predecessor custody. Zero trails is a lawful result and must never be replaced with a guessed structure.

## 8. Limits

Trail and application limits are explicit immutable records. A limit breach rejects the construction as a whole. The runtime never truncates a valid branch set and never hides branches to fit a limit.

## 9. Determinism and side-effect boundary

Construction is standard-library-only, deterministic, offline, and free of hidden global state. It performs no filesystem, network, environment, memory, route, tool, action, or delivery operation.

Stable record identities are derived only from canonical record content and accepted predecessor identities.

## 10. Non-authority statement

A complete candidate phase trail is not selected structure. A selected structure is not meaning. Meaning is not truth, permission, capability authority, routing authority, or action authority.
