# Slice 36 Operator Architecture Supersession Record

## Decision

The previously proposed **Slice 36B — Deterministic Token Stream** is
superseded before implementation.

The replacement sequence begins with:

1. Slice 36B0 — RSOC/FBSC Language Operator Runtime Contract and Legacy
   Isolation;
2. Slice 36B — Deterministic Source-Field Projection.

## Reason

A conventional word/number/punctuation token stream must not become the
cognitive or semantic foundation of Forge. Exact source coordinates may later
be represented inside a reversible source field, but FBSC/RSOC operator law—not
ordinary NLP token categories—must own transformation.

## Preserved work

No accepted implementation is invalidated.

- Slices 35A–35E remain accepted.
- Slice 36A remains accepted.
- No conventional Slice 36B tokenizer was implemented or committed.
- The MEA operator engine remains preserved in its separate ProblemManifest
  domain.
- Legacy RMC phase and resonance modules remain preserved but isolated from new
  language authority.

## Permanent distinction

Source coordinates provide operands. FBSC supplies phase structure. RSOC
supplies transformation contracts. RMC later supplies meaning construction.
MeaningStructureManifest preserves semantic custody. Later gates supply
selection and disposition.
