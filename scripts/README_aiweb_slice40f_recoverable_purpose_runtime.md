# AI.Web Slice 40F — Intended-Purport and Recoverable-Purpose Runtime

This slice installs a deterministic, non-LLM family evaluator for the fourth verbal-cognition gate.

## Runtime input

The evaluator accepts a sealed Slice 40B governance bundle plus exact purpose assertions and observations grounded in controlled candidate records. Approved discourse ancestry, reference state, or active context may be cited only when the corresponding authority is explicit.

## Runtime output

The evaluator emits immutable, deterministic, canonicalized family findings and one family-level result:

- recoverable;
- unrecoverable;
- ambiguous;
- unsupported;
- conflicted;
- indeterminate.

## No downstream consequence

The result is not gate composition, clarification, rejection, refusal, hold, selected meaning, truth, evidence, permission, execution, memory, route, tool, action, rendering, or delivery authority.
