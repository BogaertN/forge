## Decision

Slice 40F is implemented as a new sibling gate-family runtime under:

`aiweb_language_core_bootstrap.verbal_cognition_gate_runtime.recoverable_purpose_gate`

No accepted Slice 40A through 40E source is modified.

The runtime recovers only communicative purpose explicitly supported by:

1. exact candidate records;
2. approved discourse ancestry, when used;
3. authorized reference state, when used;
4. exact active context, when used;
5. accepted governing authority and provenance.

## Exact distinctions

The runtime preserves all nine canonical non-equivalences:

- mention is not request;
- inspect is not execute;
- propose is not install;
- simulate is not alter-live-state;
- report is not prove;
- retrieve-memory is not write-memory;
- ask-permission is not possess-permission;
- verify-request is not verified-status;
- delivery-meaning is not delivery-authority.

## Family-level states

The bounded runtime may return only:

- recoverable;
- unrecoverable;
- ambiguous;
- unsupported;
- conflicted;
- indeterminate because required authority is absent.

These are recoverable-purpose family results only. They are not composed gate dispositions.

## Permanent prohibitions

The runtime cannot:

- infer hidden intent;
- use assistant intuition, psychological inference, or emotional interpretation;
- infer purpose from capability existence;
- infer purpose from prior conversation habit;
- infer purpose from raw text alone;
- conflate either side of an approved distinction;
- automatically collapse multiple possible purposes;
- use unauthorized context;
- mutate candidate structure;
- create clarification, rejection, refusal relevance, or blocked progression;
- compose all four verbal-cognition gates;
- create candidate disposition or selected meaning;
- determine truth or validate evidence;
- grant permission or authorize execution;
- create capability availability, routes, tool calls, actions, memory reads or writes, rendering, or delivery;
- load external resources;
- use an LLM, embedding, vector, RAG, or semantic-similarity authority.

## Deferred authority

Slice 40G owns gate composition and non-selection disposition.
Slice 41 owns selected meaning.
