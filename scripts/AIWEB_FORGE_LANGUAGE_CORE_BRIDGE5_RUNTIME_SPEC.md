# Forge Language Core Bridge 5 Runtime Specification

## Explicit command

Candidate-only form, used to reveal lawful predicate/frame options when plurality exists:

```text
forge-language-eligibility-hold <inspect|report|request> :: <exact-candidate-id> :: <source request>
```

Exact pair form:

```text
forge-language-eligibility-hold <inspect|report|request> :: <exact-candidate-id> :: <exact-predicate-candidate-id> :: <exact-role-layout-candidate-id> :: <source request>
```

## Runtime sequence

```text
exact source custody
→ deterministic Bridge 4 candidate reconstruction
→ exact CandidateMeaning nomination verification
→ exact linked predicate/frame nomination verification
→ current Slice 38 version custody
→ Slice 40C–40F family evaluation
→ Slice 40G ordered same-candidate composition
→ Slice 40H MSM gate custody
→ Slice 41C eligibility evaluation
→ hard hold before Slice 41D
```

Where no admitted lexicon or operator authority exists, Bridge 5 supplies explicit absent-authority observations. It does not manufacture support. The expected demonstration outcome is therefore `held_pending_authority`, not selected meaning.

## Non-authority guarantees

The response is read-only evidence. It contains no command route, no approval, no execution token, no source write, no memory write, no selected meaning, and no LLM call from Forge.
