# AI.Web Slice 37C Concept Selection and Deferred-Scope Decision

## Decision

The proposed Slice 37C registry is a closed set containing exactly four concepts in exactly one namespace. No additional concept may enter through frequency, familiarity, historical occurrence, source compilation, dictionary lookup, external resource coverage, semantic similarity, or implementation need.

## Admission basis

Each selected concept is explicitly defined by Document 4 architecture and is necessary to test the registry boundary itself:

- `forge_controlled_concept_identity` defines what the governed resource is.
- `source_expression_form` prevents text from becoming concept authority.
- `concept_admission` makes the human-approved governance boundary representable.
- `unknown_concept_condition` preserves missing concept support without guessing.

## Authority limit

Admission authorizes only the exact concept identity, definition, version, namespace, scope, provenance, permitted uses, prohibited uses, and lifecycle ancestry encoded in the record. It does not establish that any concept applies to any source expression or occurrence.

## Deferred work

- Slice 37D owns controlled senses and exact term mapping.
- Slice 37E owns semantic classes and relation-type rules.
- Slice 37F owns bounded structural-to-concept candidate proposal.
- Slice 37G owns disabled integration and Slice 37 closeout.
- Slice 38 owns predicate and participant-role authority.
- Slice 39 owns CandidateMeaning construction.
- Slice 40 owns gate selection and ambiguity disposition.

## Explicit non-claims

This increment is not a general lexicon, dictionary, parser, resolver, interpretation engine, semantic graph, source-understanding system, runtime service, public API, evidence system, memory system, capability router, action engine, renderer, delivery system, release, or production-readiness declaration.
