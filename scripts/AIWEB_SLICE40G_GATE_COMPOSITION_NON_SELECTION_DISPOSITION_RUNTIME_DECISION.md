# AI.Web Slice 40G Gate Composition and Non-Selection Disposition Decision

## Decision

Slice 40G installs one deterministic candidate-specific composition runtime under
`aiweb_language_core_bootstrap.verbal_cognition_gate_runtime.gate_composition`.
It composes the exact accepted results from expectancy, congruity,
connectedness, and recoverable-purpose review by preservation, not collapse.

## Exact dispositions

The closed Slice 40G disposition vocabulary is:

1. `material_ambiguity_preserved`
2. `clarification_relevant`
3. `unsupported`
4. `refusal_relevant`
5. `held`
6. `blocked_progression`
7. `candidate_supported_for_later_selection_review`

The positive name is not invented. It is the canonical-roadmap phrase and is
consistent with the committed Slice 40A field
`positive_selection_review_disposition_created` and its deferred naming record.

## Composition law

Every composed record retains the exact identity and canonical digest of all
four family results. No gate may substitute for, waive, repair, erase, flatten,
or launder another gate. Local gate satisfaction is not a global pass, and a
local gate failure is not a global failure for other candidate branches.

## Critical non-selection boundary

`candidate_supported_for_later_selection_review` is not selected meaning,
acceptance, truth, evidence, permission, capability availability, routing,
execution, memory authority, rendering, delivery, or implementation authority.

Material ambiguity requires explicit material-ambiguity authority. Multiple
candidate records alone are insufficient. Clarification relevance requires
explicit user-suppliable missing meaning support. Missing roles alone do not
automatically create clarification. Unsupported state does not automatically
create refusal relevance. Refusal relevance does not create outward refusal.

## Preserved boundaries

Candidate branches, effect boundaries, domain-sensitive markers, no-action
boundaries, later-authority dependencies, version custody, and candidate
ancestry remain visible and immutable in the composed result.
