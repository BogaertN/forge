# Slice 40A — Verbal Cognition Gate Core Schema

This increment adds immutable typed schema contracts only.

It does not calculate identities, validate records, run expectancy, congruity,
connectedness, or recoverable-purpose evaluation, compose outcomes, create
ambiguity or clarification dispositions, reject or hold candidates, modify
MSM-v1, select meaning, determine truth, validate evidence, grant permission,
create routes, invoke tools, perform actions, access memory, render output,
deliver anything, or load external resources.

## Package

`aiweb_language_core_bootstrap.verbal_cognition_gate_runtime`

## Files

- `identity.py`: stable package, parent, and record-schema identities.
- `authority.py`: family vocabulary, companion decision, deferred scope, and
  permanent non-authority boundaries.
- `schema.py`: frozen, slotted record contracts and schema-only enums.
- `__init__.py`: explicit public exports.

## Next increment

Slice 40B owns deterministic validation, identity calculation, canonical
serialization, version custody enforcement, and lifecycle transitions. It does
not install a gate-family evaluator.
