# AI.Web Slice 40D — Congruity Gate Runtime

Slice 40D evaluates exact admitted semantic compatibility assertions without
rewriting the candidate. It distinguishes compatible, incompatible, ambiguous,
unsupported, conflicted, and indeterminate family results.

A known predicate or filled-looking role is not enough. The candidate must
preserve the exact approved relationship among concepts, senses, semantic
classes, predicate identity, frame, participant roles, speech-act force,
effect boundary, domain marker, capability reference, negation, quotation or
report scope, and correction ancestry.

This slice does not compose all four gates, create clarification or rejection,
select meaning, or authorize any downstream consequence.
