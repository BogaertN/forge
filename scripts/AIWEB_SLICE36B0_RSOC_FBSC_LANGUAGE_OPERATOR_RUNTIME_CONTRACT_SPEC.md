# AI.Web Slice 36B0 — RSOC/FBSC Language Operator Runtime Contract and Legacy Isolation

## Status

Implementation specification for the bounded Slice 36B0 increment.

## Purpose

Slice 36B0 defines the immutable runtime contracts required before exact source
custody can be projected into a resonant language field. It does not implement
source-field projection, operator binding, operator execution, phase assignment,
meaning construction, memory, routing, tools, actions or delivery.

## Source authority

The contract is grounded in:

1. Resonant Symbolic Operator Calculus, which defines exactly ten composable
   operators on Symbolic Field Elements and requires explicit domains, ranges,
   commutation relations and entropy side effects.
2. Frequency-Based Symbolic Calculus Volume II, which treats symbolic grammar
   operators as phase-intent bindings rather than conventional parts of speech.
3. RMC Language Law v1, which requires deterministic, identifiable,
   version-controlled, inspectable and trace-producing language rules while
   preserving unsupported and unresolved states.
4. Accepted Slice 36A exact input-event and source-custody records.

## Installed contract surface

The package defines:

- an unprojected source-linked resonant-language field envelope;
- a closed ten-operator RSOC registry;
- immutable per-operator contracts;
- typed refusal of every operator-application request;
- a static legacy-isolation catalog;
- deterministic validators and stable identifiers.

## Ten operator contracts

The registry contains exactly:

- ⟁ Resonance Merge;
- ⧧ Resonance Severance;
- ⧒ Recursive Amplification;
- ⧀ Symbolic Discharge / Collapse;
- ⧙ Recursive Lock / Fusion;
- ⧜ Recursive Integration / Memory;
- χ(t) Christ Function / Grace Override;
- R̂ Resurrection Reload;
- Ĉ Controlled Archival;
- Ê Echo Validation.

All ten are `contract_only_disabled`. No numeric transform, entropy threshold,
commutation table or runtime implementation is installed. Only χ(t) carries the
contract-level permission that a later proven implementation may decrease
entropy. That permission does not install a threshold, trigger or invocation.

## Field envelope boundary

A valid supported Slice 36A input event may produce one inert field envelope
that references:

- input-event identity;
- source SHA-256;
- exact byte and code-point lengths;
- root source span;
- unresolved root coverage.

The envelope remains unprojected, unphased, unassessed and uncontained. It does
not copy or replace source text and it does not tokenize, bind operators, apply
operators, resolve references, lookup concepts, bind predicates or create
meaning.

Unsupported Slice 36A input is held. Invalid or tampered input-event records are
rejected through typed results. No exception is used as the public disposition.

## Legacy isolation

The new package must not import or call legacy RMC language modules, prohibited
LLM/vector dependencies, MEA operator modules or legacy phase/phrase resources.
The MEA operator engine remains preserved in its own ProblemManifest domain but
cannot substitute for the language operator kernel.

## Permanent boundaries

- operator registration is not operator application;
- operator application is not installed;
- source custody is not source-field projection;
- an unprojected field is not an SFE interpretation;
- source hash is not RSOC ψ identity;
- a glyph is not a source binding;
- phase is not assigned;
- meaning is not created;
- MEA operators are not language operators;
- legacy phase parsing is not authority;
- phrase, word and letter maps are not authority;
- no hidden fallback exists.

## Side-effect boundary

The runtime package is standard-library only and in-memory only. It performs no
filesystem, environment, network, model, retrieval, vector, memory, database,
route, API, UI, tool, action, rendering, delivery, release or production work.

## Deferred work

Slice 36B will implement deterministic source-field projection into this
contract. Later increments will separately implement controlled operator
registration detail, source-bound candidate binding, phase trails, scope and
reference constraints, structural derivation and bootstrap integration.
