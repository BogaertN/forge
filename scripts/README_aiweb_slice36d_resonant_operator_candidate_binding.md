# Slice 36D — Resonant Operator Candidate Binding

This additive package implements the first exact source-to-operator **candidate association** boundary.

## Runtime package

`aiweb_language_core_bootstrap/resonant_operator_candidate_binding`

- `schema.py` — immutable rules, candidates, signals, binding sets, limits and results;
- `rules.py` — closed fifteen-rule deterministic catalogue;
- `binding.py` — exact source-field matching and candidate construction;
- `validation.py` — stable-identity, source-range, registry, ruleset and authority validation;
- `__init__.py` — explicit public exports.

## Important boundary

The runtime associates exact source spans with possible registered symbolic grammar operators. It does not apply those operators and does not select a meaning.

`install` and the other bounded action-like forms are retained as unresolved structural signals for later predicate analysis. They are not routed or executed.
