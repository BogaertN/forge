# Slice 36B0 implementation note

Slice 36B0 adds an isolated, additive package at:

`aiweb_language_core_bootstrap/resonant_language_operator_contract`

The package intentionally is not imported by the bootstrap root. Import it
explicitly to inspect inert contracts.

It defines exactly ten disabled RSOC operator contracts, an unprojected field
envelope anchored to accepted Slice 36A custody, typed refusal for application
attempts, validators and a static legacy-isolation catalog.

It does not project text, tokenize, normalize, bind a glyph, execute an
operator, assign a phase, create meaning, read memory, write memory, register a
route, route a tool or perform an action.
