# AI.Web Slice 36E — RSOC Core Application and Phase-Transition Boundary Decision

## Decision

Slice 36E shall construct immutable candidate grammar-state trails without activating the ten RSOC core operators and without asserting that an advisory FBSC phase affinity is an executed phase transition.

## Grounds

The accepted Slice 36B0 contracts register the ten RSOC operators as disabled contract records. Slice 36C separately registers symbolic grammar-operator responsibilities and preserves phase affinities only where explicitly sourced. Slice 36D creates unresolved source-bound operator candidates.

No accepted predecessor installs:

- a grammar-operator-to-RSOC-core-operator crosswalk;
- numeric SFE component values for language-source candidates;
- complete compatibility and commutation tables for grammar candidates;
- a phase-transition executor for the source-language bridge;
- authority to decrease or otherwise mutate entropy;
- authority to select one trail or phase.

Applying an RSOC core operator or claiming a completed numeric phase transition in Slice 36E would therefore exceed the accepted domain.

## Required implementation

Slice 36E may:

- create an immutable initial candidate symbolic field state;
- apply an authorized grammar structural effect to produce a successor candidate state;
- preserve advisory phase values as candidate metadata;
- contain an uninstalled phase transition;
- preserve conflicts, unresolved branches, suspension, rejection, drift indicators, and non-progress;
- compose only reciprocal parent-child candidate links explicitly produced by Slice 36D.

Slice 36E may not:

- invoke ⟁, ⧧, ⧒, ⧀, ⧙, ⧜, χ(t), R̂, Ĉ, or Ê;
- claim a numeric entropy change;
- synthesize an SFE tensor;
- force a Φ1–Φ9 traversal;
- choose a naturally preferred trail;
- erase a predecessor state;
- convert a trail into selected meaning, permission, capability, route, tool call, memory operation, action, or delivery.

## Future boundary

A later separately authorized increment may install a formally proven grammar-to-RSOC crosswalk and phase-transition law. Until then, every phase-bearing trail remains candidate-only and every RSOC core-operator application count remains zero.
