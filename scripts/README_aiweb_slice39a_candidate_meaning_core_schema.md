# Slice 39A — Candidate Meaning Core Schema

This increment adds immutable schema contracts only.

It does not construct a candidate meaning. It does not validate records,
calculate deterministic identities, authorize lifecycle transitions, rank
alternatives, modify MeaningStructureManifest v1, evaluate verbal cognition
gates, select meaning, determine truth, validate evidence, grant permission,
create routes, invoke tools, perform actions, access memory, render output, or
deliver anything.

## Package

`aiweb_language_core_bootstrap.candidate_meaning_construction`

## Files

- `identity.py`: stable package and schema constants.
- `authority.py`: permanent non-authority boundaries.
- `schema.py`: frozen, slotted record contracts and the closed status enum.
- `__init__.py`: explicit exports.

Slice 39B owns deterministic validation, identity, versioning, and lifecycle.
