# AI.Web Slice 40E Connectedness Gate Runtime Decision

## Decision

Implement a deterministic, fail-closed connectedness-family evaluator as a sibling package under the accepted verbal-cognition gate runtime.

## Permitted evaluation

The evaluator may review only exact admitted connection assertions for:

- source spans;
- structural ancestry;
- scope;
- attachment;
- operator trails;
- predicate/frame records;
- candidate lineage.

Each assertion names two distinct controlled record references, exact connection-basis references, source references, authority references, and one corresponding observation.

## Deterministic states

The family result preserves one of six states:

- connected;
- disconnected;
- ambiguous;
- unsupported;
- conflicted;
- indeterminate.

Precedence is fail-closed and deterministic: conflicted, unsupported, ambiguous, indeterminate, disconnected, then connected.

## Prohibited inference

The evaluator must not:

- connect records because they share an expression or manifest;
- infer A-to-C merely because A-to-B and B-to-C are admitted;
- bridge source or ancestry gaps;
- rewrite scope;
- reassign attachments;
- rewrite operator trails;
- rewire predicate/frame structure;
- merge candidate lineages;
- use similarity, embeddings, nearest-known substitution, or hidden model judgment;
- mutate the candidate;
- create clarification or rejection;
- compose all gate families;
- create a candidate disposition;
- select meaning;
- grant truth, evidence, permission, execution, route, tool, action, memory, rendering, or delivery authority.

## Consequence boundary

A disconnected family result is evidence about connectedness only. Slice 40E does not decide whether that result later becomes clarification, rejection, refusal relevance, hold, or another candidate disposition. Those consequences remain deferred to the later gate-composition slice.
