# AI.Web Slice 40C Expectancy Gate Runtime Decision

## Decision

Install a bounded deterministic expectancy evaluator as a new companion package under `verbal_cognition_gate_runtime/expectancy_gate`.

## Permitted result space

The evaluator may preserve these exact family-level findings:

1. required role missing;
2. required relation missing;
3. required complement missing;
4. required purpose information missing;
5. optional detail omitted;
6. structurally complete for expectancy;
7. indeterminate because required authority is absent, unsupported, or conflicted.

## Required inputs

The evaluator requires a valid, sealed Slice 40B governance bundle, an expectancy-family review record, an exact runtime profile, exact admitted predicate/frame requirement records, one observation per requirement, and explicit trace and provenance references.

## Hard boundaries

A family-level expectancy result is not the composed verbal-cognition gate outcome. Missing structure is not automatically clarification-required. Structural completeness is not candidate selection, truth, evidence, permission, route, tool invocation, action, memory, rendering, delivery, external-resource admission, or implementation authority.

## Existing source

No accepted Slice 35, 38, 39, 40A, or 40B source file is modified. Slice 40C adds only the exact payload listed in `AIWEB_SLICE40C_EXACT_PAYLOAD_PATHS.txt`.
