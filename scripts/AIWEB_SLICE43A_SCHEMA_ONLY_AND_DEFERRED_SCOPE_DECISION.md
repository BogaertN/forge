# AI.Web Slice 43A Schema-Only and Deferred-Scope Decision

## Accepted scope

Slice 43A may add immutable, frozen, slotted record contracts and closed enum
vocabularies for authorized-meaning references, proposed-expression references,
validation-input custody, preservation dimensions, validation findings, drift
findings, Echo dispositions, rejection, containment, trace, receipt, and an
aggregate RMC Echo schema record.

The presence of `PASSED`, `REJECTED`, and `CONTAINED` as enum vocabulary does
not mean a disposition was selected. Every disposition-bearing field is locked
to `None` and every decision/performance field is locked to `False` in 43A.

## Deferred scope

43B through 43H remain separately authorized, implemented, tested, verified,
and accepted. No later operation is pulled forward.

## Permanent boundaries

- Schema is not Echo authority.
- Reference is not admission.
- Admission is not comparison.
- Comparison is not a finding unless a later authorized comparator creates it.
- Finding is not drift materiality.
- Drift is not disposition.
- Disposition vocabulary is not a decision.
- Rejection and containment shapes are not issuance.
- Pass is not delivery.
- Rejection is not truth determination.
- Containment is not deletion.
- Selected meaning and proposed expression may not be rewritten.
- Alternatives, unresolved state, ambiguity, uncertainty, evidence status,
  qualifications, caveats, refusal, memory boundaries, resource status, and
  delivery boundaries remain preserved.
- MSM-v1 is not rewritten or migrated.
- Legacy Echo code and Slice 19 remain historical only.
- No LLM, EchoForge, embedding, vector, RAG, similarity, neural parser, hidden
  classifier, route, API, network, filesystem, memory write, tool, action, or
  delivery authority.
- GP-014 is not superseded.
